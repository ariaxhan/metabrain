# Changelog

## 1.1.2

- Aimed the packaging and docs at agent discovery: added `llms.txt` (llmstxt.org format)
  with install, registration, exact tool arguments, a three-call example, and when not to
  use metabrain; added a `## For agents` section to the README with a block an agent can
  run verbatim.
- Rewrote every MCP tool docstring so `tools/list` states the arguments and the return
  shape in one imperative sentence.
- Added MCP-oriented PyPI keywords (`mcp`, `mcp-server`, `model-context-protocol`,
  `claude-code`, `codex`, `agent-memory`, `ai-agents`).
- `server.json`: agent-search phrased `description` and a `websiteUrl`. The 2025-12-11
  schema has no keywords or tags field, so none was added.
